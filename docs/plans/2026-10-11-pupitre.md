# Mod « pupitre » — plan de réalisation

> **Pour les agents :** sous-skill obligatoire : superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans, tâche par tâche. Les étapes sont des cases à cocher (`- [ ]`).

**But :** un mod Claude Code, « pupitre », qui ajoute au-dessus de la zone de texte une jauge (contexte, limites 5 h et 7 jours) et des barres de progression pixélisées (Claude, sous-agents, autres fenêtres), plus les commandes `/pupitre`, `/jauge`, `/fil`, `/cap`, `/relais`, `/plume`.

**Architecture :** un seul plugin de « function hooks » (`pupitre/`), servi par une place de marché (`.claude-plugin/marketplace.json`) à la racine du dépôt.
- **Code pur.** Tous les calculs sont des fonctions pures, testées avec `claude plugin test` : réglages, SVG des barres, mise en forme des chiffres, suivi des tâches, fichiers partagés, textes.
- **Branchement.** Un seul fichier, `register.tsx`, relie ces fonctions aux événements de Claude Code et dessine la bande.
- **Dessin.** Sur l'application de bureau, les barres sont des `Svg` animés en CSS. Dans un terminal, ce sont des caractères `█░`.

**Technique :** TypeScript et JSX (fabrique `h`), API des mods de Claude Code 2.1.295 (`claude-code`, `claude-code/testing`), Python 3 (bibliothèque standard) pour fabriquer le son.

**Spec :** `docs/specs/2026-10-11-pupitre-design.md`. À lire avant de commencer : ce plan s'y réfère.

## Contraintes générales

- **Aucune dépendance extérieure.** npm et les CDN sont bloqués (réseau de l'entreprise) : pas de `npm install`, pas de `tsc` (il faudrait le télécharger), pas de bibliothèque. Le contrôle passe par `claude plugin validate` et `claude plugin test`.
- **Claude Code en ligne de commande.** Il n'est pas dans le PATH. Dans Git Bash :
  ```bash
  CLAUDE=$(ls -d "$(cygpath "$APPDATA")"/Claude/claude-code/*/*/claude.exe | sort -V | tail -1)
  "$CLAUDE" --version   # doit afficher 2.1.295 ou plus
  ```
- **Types de l'API.** Le fichier de référence est `<dossier temporaire>/claude/bundled-skills/<version>/<identifiant>/plugin-authoring/types/claude-code.d.ts` (le skill indique le chemin exact en se chargeant). S'il manque (nouveau processus), recharger le skill `plugin-authoring` : il le réécrit et indique son chemin. À chercher par nom (`'tool.call'`, `SvgProps`, `PromptFillArgs`…), jamais à deviner.
- **Contraintes de l'environnement des hooks.**
  - Le module tourne sans DOM ni Node : tout passe par `$`.
  - Pas de `import()` dynamique.
  - Les éléments graphiques viennent de `$.ui.resolve(e)`.
  - Un `ui.render` n'écrit jamais d'état : les écritures se font depuis un `onPress` ou un autre événement.
- **Taille des SVG.** La `source` d'un `Svg` fait au plus **131 072 caractères**. Viser moins de **125 000**.
- **Animations dans le SVG.** Seuls `opacity` et `transform` sont animés. Un bloc `@media (prefers-reduced-motion: reduce)` coupe le scintillement, les étincelles, le reflet, la gerbe et le glissement.
- **Couleurs** (spec §7, à recopier telles quelles) :
  - violet `#B2A6EE #9687E4 #7C6CDC #6452D0` ;
  - bleu `#84A8EC #6490E6 #4678DC #2C60C8` ;
  - turquoise `#5CC4BC #38B2AA #1E9C96 #10827C` ;
  - vert `#7CC280 #58B060 #3C9C48 #288037` ;
  - orange `#F5AA5F #EE9646 #E8862A #D6761E` ;
  - rouge `#E66E6E #DE5A5A #D64545 #C43737`.
- **Seuils.**
  - /fil : niveau 0 sous 1/3, 1 sous 2/3, 2 au-delà, 3 quand c'est fini. La comparaison se fait avec une marge de 1e-6, et sur le nombre de tâches finies, jamais sur une position animée.
  - /jauge : violet sous 75 %, orange sous 90 %, rouge au-delà.
- **Langue.** Tous les textes visibles sont en français.
- **Identité.** Commits signés `Eiyuo <203855181+Eiyuo@users.noreply.github.com>` (déjà réglé dans `.git/config`). Jamais d'identifiant d'entreprise ni de nom réel dans le dépôt, ni dans `relais.md`.
- **Git.** Commit à la fin de chaque tâche. **Jamais de push** sans la demande de l'utilisateur.
- **Écarts à la spec**, dus à l'API (vérifiée) :
  1. `$.fs` ne sait ni renommer ni supprimer. Les fichiers partagés (§9.3) sont donc écrits directement, et un fichier illisible est ignoré (même résultat qu'une écriture atomique pour le lecteur). Une session qui se termine écrit `actif: false` au lieu d'effacer son fichier. Les fichiers inactifs depuis plus de 15 s sont ignorés.
  2. Le mot d'étape des outils `TaskCreate`, `TaskUpdate` et `TodoWrite` est « Organisation » : ces outils reviennent souvent, et « Action » dirait mal ce qu'ils font.
  3. L'estimation sans liste de tâches avance par pas de 5 % : le dessin n'est ainsi pas refait chaque seconde.

## Points d'attention (Review Focus)

1. **Pas d'abonnement :** `rateLimits` est vide. Les deux limites affichent « — » sans planter, et la jauge reste dessinée (test dans la tâche 3).
2. **Panneau très large :** 300 colonnes ou plus. Le SVG dépasserait 131 072 caractères ; il doit grossir ses pixels et rester sous la limite (test dans la tâche 2).
3. **Texte de tâche avec `<`, `&` ou des guillemets** dans le mot d'étape ou le libellé : le SVG reste valide, car le texte est échappé (test dans la tâche 2).
4. **Exactement 1 tâche sur 3, puis 2 sur 3 :** le niveau ne bascule qu'une fois et ne revient jamais en arrière tant que le nombre de tâches finies ne baisse pas (tests dans les tâches 2 et 4).
5. **Fichier partagé à moitié écrit ou vide :** il est ignoré, et les autres sessions restent affichées (test dans la tâche 6).

Autres cas couverts par des tests : brouillon vide pour /plume (tâche 10) ; `relais.md` non écrit, donc la conversation n'est pas vidée (tâche 9) ; outil inconnu, mot « Action » (tâche 4).

- [ ] **Étape 4 : écrire `reglages.ts`**

```ts
import type { Reglages } from '../types'

export type Commande = 'pupitre' | 'jauge' | 'fil' | 'relais' | 'plume'
export const COMMANDES: readonly Commande[] = ['pupitre', 'jauge', 'fil', 'relais', 'plume']

export const AUCUN: Reglages = { jauge: false, fil: false, cap: false, relais: false, plume: false }
const TOUT: Reglages = { jauge: true, fil: true, cap: true, relais: true, plume: true }

// nom affiché, accord « allumé », accord « éteint »
const NOMS: Record<Exclude<Commande, 'pupitre'>, readonly [string, string, string]> = {
  jauge: ['jauge', 'allumée', 'éteinte'],
  fil: ['fil', 'allumé', 'éteint'],
  relais: ['bouton « Passer le relais »', 'allumé', 'éteint'],
  plume: ['bouton « Améliorer le prompt »', 'allumé', 'éteint'],
}

export function lireReglages(v: unknown): Reglages {
  const o = (typeof v === 'object' && v !== null ? v : {}) as Record<string, unknown>
  return { jauge: o.jauge === true, fil: o.fil === true, cap: o.cap === true, relais: o.relais === true, plume: o.plume === true }
}

export function toutAllume(r: Reglages): boolean {
  return r.jauge && r.fil && r.cap && r.relais && r.plume
}

export function basculer(r: Reglages, c: Commande): { reglages: Reglages; message: string } {
  if (c === 'pupitre') {
    return toutAllume(r)
      ? { reglages: { ...AUCUN }, message: 'Pupitre : tout est éteint' }
      : { reglages: { ...TOUT }, message: 'Pupitre : tout est allumé' }
  }
  const allume = !r[c]
  const [nom, oui, non] = NOMS[c]
  return { reglages: { ...r, [c]: allume }, message: `Pupitre : ${nom} ${allume ? oui : non}` }
}

export function jaugeVisible(r: Reglages): boolean {
  return r.jauge || r.relais || r.plume
}
```

- [ ] **Étape 5 : écrire `register.tsx` (commandes seulement)**

```tsx
import { atom, read, update } from 'claude-code'
import type { EngineInterface, Register } from 'claude-code'

import { AUCUN, basculer, lireReglages, type Commande } from './reglages'

type Dollar = EngineInterface // le `$` de chaque hook

const P = 'pupitre'
export const reglagesA = atom({ plugin: P, key: 'reglages' } as const, AUCUN)

const DESCRIPTIONS: Record<Commande, string> = {
  pupitre: 'Allume tout le pupitre (ou l éteint si tout est déjà allumé)',
  jauge: 'Allume ou éteint la jauge (contexte, limites 5 h et 7 jours)',
  fil: 'Allume ou éteint les barres de progression de Claude et des sous-agents',
  relais: 'Allume ou éteint le bouton « Passer le relais »',
  plume: 'Allume ou éteint le bouton « Améliorer le prompt »',
}

export const register: Register = on => {
  on('session.start', async ($, e, next) => {
    for (const name of Object.keys(DESCRIPTIONS) as Commande[]) {
      await $.command.register({ name, description: DESCRIPTIONS[name] })
    }
    const garde = lireReglages(await $.store.get('reglages'))
    await update($, reglagesA, () => garde)
    return next(e)
  })

  const bascule = (c: Commande) => async ($: Dollar) => {
    const { reglages, message } = basculer(await read($, reglagesA), c)
    await update($, reglagesA, () => reglages)
    await $.store.set('reglages', reglages)
    $.ui.toast(message)
    return { text: message }
  }
  on('command.run', { command: 'pupitre' }, bascule('pupitre'))
  on('command.run', { command: 'jauge' }, bascule('jauge'))
  on('command.run', { command: 'fil' }, bascule('fil'))
  on('command.run', { command: 'relais' }, bascule('relais'))
  on('command.run', { command: 'plume' }, bascule('plume'))
}
```

```ts
// Les cases sont regroupées par (couleur, classe) en un seul <path> : le SVG reste court.
class Groupes {
  private m = new Map<string, string[]>()
  case(fill: string, cls: string, x: number, y: number, w: number, h: number): void {
    const cle = `${fill}|${cls}`
    const l = this.m.get(cle) ?? []
    l.push(`M${x} ${y}h${w}v${h}h${-w}z`)
    this.m.set(cle, l)
  }
  svg(extra = ''): string {
    let s = ''
    for (const [cle, segs] of this.m) {
      const [fill, cls] = cle.split('|')
      s += `<path${cls ? ` class="${cls}"` : ''} fill="${fill}"${extra} d="${segs.join('')}"/>`
    }
    return s
  }

function teinte(palette: readonly string[], t: number, fini: boolean, i: number, j: number, rows: number): string {
  const g = (fini ? 0.55 : 0.15 + 0.75 * t) * 3
  const lo = Math.floor(g)

  else if (j === rows - 1) c = sombre(c, 0.12)
  return c
}
```

```ts
import type { Mesure, Mesures } from '../types'

export const TIRET = '—'
export const MESURES_VIDES: Mesures = {
  contexte: { pct: null, detail: TIRET },
  cinqH: { pct: null, detail: TIRET },
  septJ: { pct: null, detail: TIRET },
}

export function kilo(n: number): string {
  if (n < 1000) return String(Math.round(n))
  if (n < 1_000_000) return `${Math.round(n / 1000)} k`
  return `${(n / 1_000_000).toFixed(1).replace('.', ',')} M`
}

export function dureeAvant(resetsAt: string | undefined, maintenant: number): string {
  if (!resetsAt) return ''
  const t = Date.parse(resetsAt)
  if (Number.isNaN(t)) return ''
  const min = Math.floor((t - maintenant) / 60000)
  if (min <= 0) return 'remise à zéro imminente'
  if (min < 60) return `remise à zéro dans ${min} min`
  const h = Math.floor(min / 60)
  if (h < 24) return `remise à zéro dans ${h} h ${String(min % 60).padStart(2, '0')}`
  return `remise à zéro dans ${Math.floor(h / 24)} j ${h % 24} h`
}

export function formatPct(pct: number | null): string {
  return pct === null ? TIRET : `${Math.round(pct)} %`
}

export type UsageLu = {
  context: { tokens?: number; window: number; percent?: number }
  rateLimits: readonly { kind: string; percentUsed: number; resetsAt?: string }[]
}

function limite(u: UsageLu, kind: string, maintenant: number): Mesure {
  const l = u.rateLimits.find(r => r.kind === kind)
  if (!l) return { pct: null, detail: TIRET }
  return { pct: l.percentUsed, detail: dureeAvant(l.resetsAt, maintenant) || TIRET }
}

export function lireMesures(u: UsageLu, maintenant: number): Mesures {
  const c = u.context
  const brut = c.percent ?? (c.tokens !== undefined && c.window > 0 ? (c.tokens / c.window) * 100 : null)
  const pct = brut === null ? null : Math.round(brut * 10) / 10 // 42, pas 41.99999999999999
  const detail = c.tokens !== undefined ? `${kilo(c.tokens)} / ${kilo(c.window)} jetons` : `fenêtre de ${kilo(c.window)} jetons`
  return {
    contexte: { pct, detail },
    cinqH: limite(u, 'five_hour', maintenant),
    septJ: limite(u, 'seven_day', maintenant),
  }
}
```

```tsx
import { formatPct } from './jauge'

export const PX_COL = 8 // pixels par colonne de la bande sur l'application (à confirmer, tâche 11)

export type Elements = Record<string, (props: Record<string, unknown>) => unknown>
export type Bouton = { cle: string; libelle: string; action: () => void }

function mesure(T: Elements, surface: string, nom: string, m: Mesure, largeurCol: number, majLe: number) {
  const { Box, Text, Svg } = T as Record<string, (p: Record<string, unknown>) => unknown>
  const pct = m.pct ?? 0
  const barre = surface === 'terminal' || Svg === undefined
    ? <Text dimColor>{barreTexte(pct / 100, Math.max(6, largeurCol - 2))}</Text>
    : <Svg source={svgSimple({ largeur: largeurCol * PX_COL, hauteur: 10, cellule: 2, rayon: 4, progression: pct / 100, palette: PALETTES_JAUGE[couleurJauge(pct)], graine: graineDe(nom), majLe })} alt={`${nom} : ${formatPct(m.pct)}`} isInteractive />
  return (
    <Box flexDirection="column" flexGrow={1}>
      <Box flexDirection="row" justifyContent="space-between">
        <Text dimColor>{nom}</Text>
        <Text bold>{formatPct(m.pct)}</Text>
      </Box>
      {barre}
      <Text dimColor wrap="truncate">{m.detail}</Text>
    </Box>
  )
}

export function dessinerJauge(T: Elements, surface: string, colonnes: number, mesures: Mesures, montrerMesures: boolean, boutons: readonly Bouton[], majLe: number) {
  const { Box, Button } = T as Record<string, (p: Record<string, unknown>) => unknown>
  const placeBoutons = boutons.reduce((n, b) => n + b.libelle.length + 6, 0)
  const largeurCol = Math.max(10, Math.floor((colonnes - placeBoutons) / 3) - 2)
  return (
    <Box flexDirection="row" gap={2} alignItems="flex-end">
      {montrerMesures && mesure(T, surface, 'Contexte', mesures.contexte, largeurCol, majLe)}
      {montrerMesures && mesure(T, surface, 'Limite 5 h', mesures.cinqH, largeurCol, majLe)}
      {montrerMesures && mesure(T, surface, 'Limite 7 jours', mesures.septJ, largeurCol, majLe)}
      {boutons.map(b => <Button key={b.cle} label={b.libelle} onPress={() => b.action()} />)}
    </Box>
  )
}
```

```ts
import type { LigneFil } from '../types'
import { niveauDe } from './pixels'

export type StatutTache = 'pending' | 'in_progress' | 'completed'
export type Tache = { id: string; sujet: string; statut: StatutTache }
export type Suivi = { taches: Tache[]; mot: string; debut: number; fin: number | null; crees: number }
export type Vue = { tache: string; compteur: string; progression: number; faites: number; total: number; estime: boolean }

const MOTS: Record<string, string> = {
  Read: 'Lecture', NotebookRead: 'Lecture',
  Grep: 'Recherche', Glob: 'Recherche', ToolSearch: 'Recherche',
  Edit: 'Écriture', Write: 'Écriture', NotebookEdit: 'Écriture',
  Bash: 'Commande', PowerShell: 'Commande',
  Agent: 'Délégation', Workflow: 'Délégation', SendMessage: 'Délégation',
  WebFetch: 'Web', WebSearch: 'Web',
  AskUserQuestion: 'Question',
  Skill: 'Méthode',
  TaskCreate: 'Organisation', TaskUpdate: 'Organisation', TodoWrite: 'Organisation',
}

export function motEtape(outil: string): string {
  const m = MOTS[outil]
  if (m) return m
  if (outil.startsWith('mcp__Claude_Browser') || outil.startsWith('mcp__claude-in-chrome')) return 'Web'
  if (outil.startsWith('mcp__')) return 'Connecteur'
  return 'Action'
}

export function nouveauSuivi(debut: number): Suivi {
  return { taches: [], mot: 'Réflexion', debut, fin: null, crees: 0 }
}

export function debutTour(s: Suivi, maintenant: number): Suivi {
  const enCours = s.taches.some(t => t.statut !== 'completed')
  return { taches: enCours ? s.taches : [], mot: 'Réflexion', debut: maintenant, fin: null, crees: enCours ? s.crees : 0 }
}

function objet(v: unknown): Record<string, unknown> {
  return typeof v === 'object' && v !== null ? (v as Record<string, unknown>) : {}
}
function statut(v: unknown): StatutTache | null {
  return v === 'pending' || v === 'in_progress' || v === 'completed' ? v : null
}

export function appliquerAppel(s: Suivi, outil: string, entree: unknown, resultat: unknown): Suivi {
  const e = objet(entree)
  let { taches, crees } = s
  if (outil === 'TaskCreate') {
    crees += 1
    const tache = objet(objet(resultat).task)
    const id = typeof tache.id === 'string' ? tache.id : String(crees)
    const sujet = typeof e.subject === 'string' ? e.subject : typeof tache.subject === 'string' ? tache.subject : `Tâche ${crees}`
    taches = [...taches, { id, sujet, statut: 'pending' }]
  } else if (outil === 'TaskUpdate' && typeof e.taskId === 'string') {
    if (e.status === 'deleted') taches = taches.filter(t => t.id !== e.taskId)
    else taches = taches.map(t => t.id !== e.taskId ? t : {
      ...t,
      statut: statut(e.status) ?? t.statut,
      sujet: typeof e.subject === 'string' ? e.subject : t.sujet,
    })
  } else if (outil === 'TodoWrite' && Array.isArray(e.todos)) {
    taches = e.todos.map((t, i) => {
      const o = objet(t)
      return { id: String(i + 1), sujet: typeof o.content === 'string' ? o.content : `Tâche ${i + 1}`, statut: statut(o.status) ?? 'pending' }
    })
    crees = taches.length
  }
  return { ...s, taches, crees, mot: motEtape(outil) }
}

export function etape(s: Suivi, outil: string): Suivi {
  return { ...s, mot: motEtape(outil) }
}

export function finir(s: Suivi, maintenant: number): Suivi {
  return { ...s, fin: maintenant, mot: '✓ Fini' }
}

export function estimation(ms: number): number {
  return 0.9 * (1 - Math.exp(-Math.max(0, ms) / 40_000))
}

export function vue(s: Suivi, maintenant: number): Vue {
  const total = s.taches.length
  const faites = s.taches.filter(t => t.statut === 'completed').length
  if (s.fin !== null) {
    return {
      tache: total > 0 ? `Terminé · ${total} tâche${total > 1 ? 's' : ''}` : 'Terminé',
      compteur: total > 0 ? `${total} / ${total}` : '✓',
      progression: 1, faites: total, total, estime: false,
    }
  }
  if (total > 0) {
    const i = s.taches.findIndex(t => t.statut === 'in_progress')
    const j = i >= 0 ? i : s.taches.findIndex(t => t.statut === 'pending')
    return {
      tache: j >= 0 ? `Tâche ${j + 1} · ${s.taches[j]!.sujet}` : 'Tâches faites',
      compteur: `${faites} / ${total}`,
      progression: faites / total, faites, total, estime: false,
    }
  }
  const p = Math.floor(estimation(maintenant - s.debut) * 20) / 20
  return { tache: 'En cours', compteur: '≈', progression: p, faites: 0, total: 0, estime: true }
}

export function ligneDe(id: string, qui: string, s: Suivi, maintenant: number, p: LigneFil | undefined): LigneFil {
  const v = vue(s, maintenant)
  const fini = s.fin !== null
  const niveau = niveauDe(v.progression, fini)
  const changeProg = !p || p.progression !== v.progression
  const changeNiv = !p || p.niveau !== niveau
  const change = changeProg || changeNiv || !p || p.mot !== s.mot || p.tache !== v.tache || p.compteur !== v.compteur || p.fini !== fini
  return {
    id, qui, tache: v.tache, mot: s.mot, compteur: v.compteur,
    progression: v.progression,
    avant: !p ? 0 : changeProg ? p.progression : v.progression,
    niveau,
    niveauAvant: !p ? niveau : changeNiv ? p.niveau : niveau,
    fini,
    eclat: fini && !(p?.fini ?? false),
    debut: s.debut,
    majLe: change ? maintenant : p!.majLe,
    finiLe: fini ? (p?.finiLe ?? maintenant) : null,
  }
}
```

```ts
export function chrono(ms: number): string {
  const s = Math.max(0, Math.floor(ms / 1000))
  const h = Math.floor(s / 3600)
  const m = Math.floor((s % 3600) / 60)
```

```ts
import type { Autre, LigneFil, Niveau } from '../types'

export const PERIME_MS = 15_000

export type Fiche = {
  id: string; titre: string; tache: string; compteur: string; progression: number
  niveau: Niveau; debut: number; majLe: number; actif: boolean
}

export function ficheDe(id: string, titre: string, l: LigneFil | undefined, maintenant: number): Fiche {
  return {
    id, titre,
    tache: l?.tache ?? '', compteur: l?.compteur ?? '', progression: l?.progression ?? 0,
    niveau: l?.niveau ?? 0, debut: l?.debut ?? maintenant, majLe: maintenant,
    actif: l !== undefined && !l.fini,
  }
}

export function lireFiche(texte: string): Fiche | null {
  let v: unknown
  try { v = JSON.parse(texte) } catch { return null }
  if (typeof v !== 'object' || v === null || Array.isArray(v)) return null
  const o = v as Record<string, unknown>
  const s = (k: string) => typeof o[k] === 'string'
  const n = (k: string) => typeof o[k] === 'number' && Number.isFinite(o[k])
  if (!s('id') || !s('titre') || !s('tache') || !s('compteur') || !n('progression') || !n('debut') || !n('majLe') || typeof o.actif !== 'boolean') return null
  const niveau = o.niveau === 0 || o.niveau === 1 || o.niveau === 2 || o.niveau === 3 ? o.niveau : 0
  return {
    id: o.id as string, titre: o.titre as string, tache: o.tache as string, compteur: o.compteur as string,
    progression: o.progression as number, niveau, debut: o.debut as number, majLe: o.majLe as number, actif: o.actif as boolean,
  }
}

export function autresActives(fiches: readonly (Fiche | null)[], moi: string, maintenant: number): Autre[] {
  return fiches
    .filter((f): f is Fiche => f !== null && f.id !== moi && f.actif && maintenant - f.majLe <= PERIME_MS)
    .sort((a, b) => a.debut - b.debut)
    .map(f => ({ id: f.id, titre: f.titre, tache: f.tache, compteur: f.compteur, progression: f.progression, niveau: f.niveau, debut: f.debut, majLe: f.majLe }))
}

export function nomFichier(id: string): string {
  return id.replace(/[^A-Za-z0-9_-]/g, '_') + '.json'
}

export function titreDe(cwd: string): string {
  const parts = cwd.split(/[\\/]/).filter(p => p.length > 0)
  return parts[parts.length - 1] ?? 'Session'
}
```

```python
"""Fabrique pupitre/assets/carillon.wav : carillon doux de 2 notes (mi 5 puis la 5), environ 0,7 s.

Bibliothèque standard seulement. Lancer depuis la racine du dépôt : python outils/carillon.py
"""
import math
import struct
import wave
from pathlib import Path

TAUX = 44100
DUREE = 0.75
NOTES = [  # (fréquence Hz, départ s, durée s)
    (659.25, 0.00, 0.45),
    (880.00, 0.18, 0.55),
]


def echantillon(t: float) -> float:
    v = 0.0
    for f, debut, duree in NOTES:
        u = t - debut
        if 0 <= u <= duree:
            attaque = min(1.0, u / 0.008)                 # 8 ms : pas de clic
            decroit = math.exp(-u * 5.5)                  # extinction douce
            onde = math.sin(2 * math.pi * f * u) + 0.25 * math.sin(2 * math.pi * 2 * f * u)
            v += 0.32 * attaque * decroit * onde
    return max(-1.0, min(1.0, v))


def main() -> None:
    cible = Path(__file__).resolve().parent.parent / "pupitre" / "assets" / "carillon.wav"
    cible.parent.mkdir(parents=True, exist_ok=True)
    n = int(TAUX * DUREE)
    with wave.open(str(cible), "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(2)
        w.setframerate(TAUX)
```

```ts
export type Capacite = { sorte: 'commande' | 'outil' | 'connecteur' | 'sous-agent'; nom: string; description: string }

export const SYSTEME_PLUME =
  "Tu réécris la demande qu'un utilisateur s'apprête à envoyer à Claude Code, pour qu'elle soit précise et complète. " +
  "Règles : garde sa langue et son intention ; n'invente aucun fait, aucun fichier, aucune contrainte ; rends explicites " +
  "le but, le contexte utile, les contraintes et le résultat attendu ; si un outil, une commande, un connecteur ou un " +
  "sous-agent de la liste fournie sert vraiment, cite-le par son nom exact (une commande s'écrit avec « / ») ; reste court " +
  "et direct, en tutoyant ; réponds uniquement par le texte réécrit, sans titre, sans guillemets, sans commentaire."

const MAX_CAPACITES = 150

export function promptPlume(brouillon: string, capacites: readonly Capacite[]): string {
  const liste = capacites.slice(0, MAX_CAPACITES)
    .map(c => `- ${c.sorte} ${c.sorte === 'commande' ? '/' : ''}${c.nom} : ${c.description.replace(/\s+/g, ' ').slice(0, 140)}`)
    .join('\n')
  return `Ce dont Claude dispose dans cette session :\n${liste}\n\nDemande à réécrire :\n<<<\n${brouillon}\n>>>`
}

export function nettoyerReponse(texte: string): string {
  let t = texte.trim()
  t = t.replace(/^```[a-z]*\n?/i, '').replace(/\n?```$/, '')
  t = t.replace(/^<<<\n?/, '').replace(/\n?>>>$/, '')
  return t.trim()
}
```
